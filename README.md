# Детский журнал

Android-приложение для ведения журнала температуры и приёма лекарств у двух детей.

## Скачать APK

**[Скачать последнюю версию приложения](https://github.com/umnyj0810/DetskiyZhurnal/releases/latest/download/DetskiyZhurnal.apk)**

Все версии доступны на странице [GitHub Releases](https://github.com/umnyj0810/DetskiyZhurnal/releases).

## Возможности
- два отдельных профиля с возможностью менять имена детей;
- запись температуры и комментария;
- запись названия лекарства и дозировки;
- автоматическая дата и время;
- история записей по каждому ребёнку;
- удаление ошибочных записей;
- локальное хранение на устройстве, без интернета.

## Установка
1. Открой ссылку скачивания на Android-телефоне.
2. Скачай файл `DetskiyZhurnal.apk`.
3. Открой скачанный файл.
4. Если Android попросит разрешение, разреши установку приложений из этого источника.

Сборка APK и публикация в GitHub Releases запускаются автоматически при каждом push в ветку `main`. Файл также доступен как артефакт GitHub Actions в течение 30 дней.

> Сейчас публикуется debug-сборка для распространения и тестирования. Приложение хранит записи локально на устройстве. Это журнал записей, а не система назначения лечения: дозировки и интервалы приёма лекарств сверяй с назначением врача и инструкцией.
