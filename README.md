# Детский журнал

Android-приложение для ведения журнала температуры и приёма лекарств у двух детей.

## Возможности первой версии
- два отдельных профиля;
- запись температуры и комментария;
- запись названия лекарства и дозировки;
- автоматическая дата и время;
- история записей по каждому ребёнку;
- удаление ошибочных записей;
- локальное хранение на устройстве, без интернета.

## Как получить APK
1. Открой вкладку **Actions** в репозитории.
2. Выбери workflow **Build Android APK**.
3. Нажми **Run workflow** и подтверди запуск (если сборка ещё не стартовала автоматически).
4. Дождись зелёной галочки у завершённой сборки.
5. Открой сборку и в разделе **Artifacts** скачай **DetskiyZhurnal-debug-apk**.
6. Распакуй ZIP-архив и установи app-debug.apk на Android.

Сборка также запускается автоматически при каждом push в ветку main.

> Первая версия — журнал записей, а не система назначения лечения. Дозировки и интервалы приёма лекарств сверяй с назначением врача и инструкцией.
